# 卡片规范（Card Schema）

本文件定义"知识卡片"三要素的写法细则，供撰写与自检时查阅。

## 一、卡片整体结构

```
## <标题>

**核心内容**
...

**批注解释**
...

---
```

- 字段名固定为 `**核心内容**` 与 `**批注解释**`，不要改动，以便 `scripts/render_deck.py` 解析。
- 每张卡片之间用一行 `---` 分隔。
- 一张卡片只讲一个知识点。

## 二、标题（Title）

**目标**：读者只看标题就能回忆起这个知识点。

**规则**
- 写成一句能独立成立的**陈述或名词性判断**，自带信息量。
- 长度建议 8–20 字，避免疑问句堆砌、避免口号化。
- 不含原文没有的结论；不得夸大核心内容的范围。

| ✅ 好标题 | ❌ 差标题 | 原因 |
|---|---|---|
| 复利效应：时间放大收益差异 | 第一点 | 空标题，无信息 |
| 睡眠通过"记忆固化"增强长期记忆 | 关于睡眠 | 无判断，不可复述 |
| 番茄工作法用固定短周期对抗拖延 | 番茄工作法 | 只有名词，未说明知识点 |

## 三、核心内容（Core Content）

**目标**：准确承载原文这一个知识点，可回溯。

**规则**
1. 优先**直接引用**：用 `「…」` 括起原文，并在括号内标段落位置，如 `「……」（第 3 段）`。
   - 引用**必须逐字**：与原文一字不差，含标点、数字与原文内部的引号；省略中间内容写 `「前……后」`。宁可改用无引号的最小改写，也不要"伪引用"。
2. 不能直接引用时，做**最小改写**：只调整语序/省略冗余，不改变语义、不增删条件、不换概念。
3. 一篇/一段原文含多个知识点时，本字段只保留属于本卡片的那一个。
4. 严禁出现原文没有的事实、数据、因果、评价。

**最小改写的边界**
- ✅ 允许：合并同义重复、把代词补成名词、调整从句顺序。
- ❌ 禁止：把"可能/通常"改成"一定/总是"；把"相关"改成"导致"；补一句原文没有的结论。

## 四、批注解释（Annotation）

**目标**：帮助读者真正理解这个知识点——它是什么、为什么重要、容易误解在哪。

**可写内容**
- 术语释义、背景前提。
- "为什么重要"、与知识的联系。
- 常见误解、适用边界、反例。

**来源标注（强制）**
- `补充：` … 你在原文之外引入的知识。
- `推断：` … 由你推导、原文未明说的结论。
- 无前缀 … 对原文内容的解释或重要性说明。

**禁止**
- 把批注中的观点伪装成原文观点。
- 用批注"救场"——如果核心内容本身就偏离原文，应先修正核心内容，而不是在批注里打补丁。
- 批注喧宾夺主：一般 1–3 句即可，不写成长篇评论。

## 五、重要性筛选清单

**保留（高价值）**
- [ ] 文章的核心论点 / 最终结论
- [ ] 关键定义、术语的准确含义
- [ ] 原理与机制（"为什么"）
- [ ] 关键数据、实验证据、案例结论
- [ ] 方法与可操作步骤
- [ ] 成立条件、例外、前提
- [ ] 反直觉、易被误解的要点

**舍弃（低价值）**
- [ ] 客套、铺垫、过渡句
- [ ] 重复表述、同义反复
- [ ] 纯修辞、情绪渲染、口号
- [ ] 与主题无关的轶事、题外话
- [ ] 读者已知的常识性铺垫

## 六、篇幅与张数参考（经验值，非硬性）

| 原文篇幅 | 建议卡片数 | 说明 |
|---|---|---|
| < 800 字 | 3–7 张 | 短文，聚焦核心结论 |
| 800–3000 字 | 6–16 张 | 常规文章 |
| > 3000 字 | 16 张以上 | 长文按章节分组，可加小标题分区 |

原则：**最终以知识点数量为准，篇幅只是参考**。一张卡片 = 一个知识点，因此密实的短文也可能产出较多卡片。**宁少而准，不多而水**；若两张卡片可被一句话合并，就合并。

## 七、修改前后对照示例

**原文片段（第 2 段）**
> 番茄工作法把工作切成 25 分钟的专注时段，每个时段之间休息 5 分钟。它的原理不是"逼自己更努力"，而是用固定的短周期降低开始工作的心理门槛。

**❌ 不合格卡片**
```
## 番茄工作法
**核心内容**
番茄工作法能让人更高效、更专注，是提升生产力的最佳方法。
**批注解释**
很多人都用这个方法。
```
问题：① 标题无信息；② 核心内容掺入原文没有的"最佳方法"、丢失了"25 分钟/5 分钟/降低心理门槛"等要点；③ 批注无价值。

**✅ 合格卡片（可拆为两张，此处合为一张展示结构）**
```
## 番茄工作法用固定短周期降低开工心理门槛

**核心内容**
番茄工作法把工作切成「25 分钟的专注时段，每个时段之间休息 5 分钟」。其原理不是"逼自己更努力"，而是「用固定的短周期降低开始工作的心理门槛」。

**批注解释**
关键在于"降低启动阻力"：把大任务变成 25 分钟即可开始的小块，比靠意志力硬撑更可持续。补充：25/5 是常见默认值，实际可按个人节奏调整。

---
```

## 八、自检（写完整篇后逐卡过一遍）

- [ ] 每张卡只有一个知识点
- [ ] 标题自带信息、可复述
- [ ] 核心内容全部可回溯原文
- [ ] 原文引用用 `「」` 且标注段落
- [ ] 批注中的外部知识与推断已用 `补充：` / `推断：` 标注
- [ ] 没有夸大、绝对化、丢失限定条件
- [ ] 重要知识点未被遗漏
